STW Anti-Air Team

Turn an existing soldier into an anti-air gunner or assistant gunner, or let the server deploy autonomous two-person air-defence teams across the scenario.

What it adds

STW Anti-Air Team equips a selected character as either an Anti-Air Gunner or an Assistant Gunner. The gunner receives the faction-appropriate AI launcher; the assistant carries the team’s virtual reload stock. Both keep their existing clothing, while the system replaces and supplies the role equipment, magazines, grenades, medical supplies, navigation and observation gear.

Anti-Air Gunner

Receives the launcher and a configurable primary-weapon package. The system uses the US Stinger or USSR Igla family according to the soldier’s faction.

Assistant Gunner

Receives a configured number of virtual reloads. When close to the gunner, the assistant enables launcher replacement after the gunner has expended it.

Automatic pairs

The server can discover suitable terrain and elevated structural positions, deploy pairs, replace casualties, and later relocate surviving teams.

For players

No player menu is required. On a server running the mod, automatic teams are hostile or friendly according to their faction. They protect a small operating area and may relocate after their guard period.

  • When the server enables intelligence reports, the opposing faction receives an approximate map report after deployment and at the configured interval. Reports are disabled by default.
  • Do not separate a managed pair if you expect its reload support to work: the assistant must be inside the configured transfer distance (50 m by default).
  • Automatic teams avoid spawning near players. The default protected radius is 1,500 m, so a team will not suddenly appear beside an active player area.

For Game Masters

Select an existing soldier and use the General context actions Assign Anti-Air Gunner or Assign Assistant Gunner. The request is sent to the authoritative server, which validates the character and applies the role loadout. Use the two actions on suitable soldiers of the same faction to create a manually managed team.

Open Scenario Properties and select the STW Anti-Air tab to change the default camouflage, weapons, optics, night vision, ammunition and balaclava choices for future assignments. These settings are saved by the server; they do not retroactively alter already assigned soldiers.

Session switch: Automatic AntiAir/AssistantGunner Pair Generator in Scenario Properties controls only the automatic system. Turning it off removes system-created pairs; manually assigned gunners and assistants remain. Turning it back on starts the configured automatic system again.

Automatic pair system

Automatic deployment runs server-side. It scans the world incrementally, caches viable terrain positions, and can score usable elevated structures such as roofs. Structural positions are preferred 60% of the time by default when available. The system excludes unsuitable structures such as piers, bridges and walls, and can be tuned or diagnosed through its JSON files.

Defaults allow up to three pairs per faction and six initial pairs in total. A destroyed pair is eligible for replacement after a randomized 30–60 minute delay. Surviving teams guard their area for 1–3 hours, then may relocate 1.5–8 km to another player-clear candidate. The defaults are deliberately conservative; raise limits only after checking server performance and the map’s available space.

Server setup and configuration

  1. Install STW Anti-Air Team and its required dependencies on the server and clients, then start the desired scenario once.
  2. The mod creates its JSON files under $profile:STW/AntiAir/. Stop the server before editing them.
  3. Back up the file, make your changes using valid JSON, restart the server, and review the log for validation messages. Values outside safe ranges are clamped and the validated configuration is saved.
FilePurpose and key defaults
STWAntiAirTeamConfig.jsonManual-assignment loadouts: camouflage, primary weapons, optics, night vision, ammunition, grenades and launcher support. Defaults include 5–7 magazines, 3 fragmentation and 3 smoke grenades, a 60-second reload check, 50 m transfer range and 2 assistant missiles.
Support/STWAntiAirTeamSupportConfig.jsonManaged-unit resupply and healing. Defaults: daily resupply, assistant AA-ammo replenishment every 2 hours, 20% healing probability, 25% healing amount. allowPlayerManagedUnitResupply is false by default.
AutoPairs/STWAntiAirPairAutoConfig.jsonAutomatic terrain discovery, faction selection, limits, respawn, relocation and optional intelligence reports. It enables automatic pairs by default; enabledFactionKeys can restrict the system and excludedFactionKeys defaults to ["CIV"].
StructuralOverwatch/STWAntiAirStructuralOverwatchConfig.jsonDedicated structural scanning, eligibility and diagnostics. Structural discovery, use and ambush relocation are enabled by default; diagnostics are off.
Safe operation: automatic scanning is deliberately batched to reduce frame impact. Avoid increasing scan batches, candidate limits, active-pair limits and diagnostics together. Change one category at a time and test on the target map.

Soft dependencies and optional mod support

STW Anti-Air Team runs without the mods below. They are detected through available prefabs: when unavailable, the mod uses its vanilla-compatible loadout options or skips only the optional item. Install optional content normally on both server and clients; adding a choice in configuration does not download or load a mod.
