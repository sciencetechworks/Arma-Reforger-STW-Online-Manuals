Recommended companion: STWCombatKnowledge

For the best experience, run STW Divide and Conquer together with STWCombatKnowledge. Divide and Conquer can start without it, but the campaign's strategic CQB and Stronghold encounters work substantially better when CombatKnowledge is enabled.

STWCombatKnowledge provides the shared perception and combat-awareness layer that helps spawned forces respond coherently to nearby players, units, and combat activity. This makes frontline confrontations feel more alive and improves the quality of tactical reactions inside campaign-generated encounters.

Load STWCombatKnowledge on both the server and clients alongside Divide and Conquer, and keep both mods updated to compatible versions. CombatKnowledge is recommended, not a hard requirement for the campaign to start.

For CombatKnowledge setup and behavior settings, see the STWCombatKnowledge manual.

Configuration

Basic ownership persistence is stored separately at $profile:STW/Persistence/DivideAndConquer/STW_DivideAndConquerOwnership_<map signature>.json. It restores only Red and Blue cell ownership. Active tokens, confrontations, timers, and events restart with the server.

The file is generated at $profile:STW/DivideAndConquer/STW_DivideAndConquerCampaignConfig.json. Delete or edit it, then restart the server to apply structural changes.

Strategic Stronghold profile: each generated Stronghold samples its buildings, units, patrols, and shooters from the configured minimum and maximum ranges. Roof and tower shooters remain enabled for strategic Strongholds. The sampled values are fixed for that Stronghold encounter.
Strategic CQB: each token receives random occupation time and kill requirements from the configured ranges. Its faction percentage is also randomized per zone. Strategic Stronghold: each token receives a random lifetime and a random soldier-loss defeat percentage when deployed. These values remain fixed for that encounter.

Complete configuration reference

All campaign settings are stored in $profile:STW/DivideAndConquer/STW_DivideAndConquerCampaignConfig.json. The ownership cache is separate: $profile:STW/Persistence/DivideAndConquer/STW_DivideAndConquerOwnership_<map signature>.json. The campaign file is schema version 2; restart the server after editing it.
