Overview

STW Light Vehicle Spawner provides scenario controls for manual and automatic light-vehicle spawning. It remains usable with its core available content; optional vehicles are offered only when their prefabs can be loaded successfully.

Soft dependencies and optional Tactical Flava support

The Tactical Flava TIGR vehicles are an optional integration, not a hard requirement. If either source mod is absent, STW Light Vehicle Spawner continues to work and simply excludes unavailable TIGR entries. For multiplayer, enable the selected optional content and its dependencies on both the server and clients.
