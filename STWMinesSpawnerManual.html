STW Mines Spawner

A server-side minefield population mod for Arma Reforger by Bohemia Interactive. It creates configurable anti-personnel and anti-tank minefields on official and community terrains, then restores surviving mines for the same scenario and terrain.

STW suite connection

STW Mines Spawner is the public manual name for STW Persistent Mines GMP, made by STW (ScienceTechWorks). It is a server-authoritative, self-contained minefield system; no other STW mod is required for its core behavior. Its configuration and persistence files are stored under the STW profile folders alongside the wider suite.

What it adds

After a configurable startup delay, the server generates anti-tank (AT) mine groups and optional anti-personnel (AP) mines at suitable locations. It can use US mines, USSR mines, or a randomized mixture. Separate category-distribution files let an administrator weight the kinds of locations used for AP and AT placement.

Two mine categories

AT groups are generated independently from AP mines. You can disable AP mines entirely, tune their total cap and per-location count, while retaining AT minefields.

Terrain-aware preferences

AP and AT distribution profiles control the selection weight for military bases, checkpoints, guard posts, bridges, industry, camps, harbours, roads, coastal access points, and other recognised locations.

Map awareness

Optional markers can be enabled separately for AP and AT mines. Marker positions can be exact or displaced by a configured maximum distance.

For players

There is no player menu or client-side setup. Minefields are part of the running scenario. Treat any mine marker as an administrator-selected aid, not an assurance that every danger is visible or that a marker is exact.

  • AP and AT map markers can be enabled separately by the server administrator.
  • With approximate markers enabled, the marker may be offset from the actual mine by up to the configured distance.
  • Minefields persist only according to the server’s configuration and save state; do not assume a location is safe after a restart.

For Game Masters and scenario hosts

STW Mines Spawner automatically manages its generated minefields on the server. It does not add a separate Game Master placement menu. Game Masters can use normal live-world tools, while mine type, population, safe zones, markers, preferences, and persistence remain administrator settings.

For Conflict scenarios, an optional protected radius can prevent eligible AT mines from being generated near Conflict bases. Set safeZonesHQOnly to restrict protection to headquarters, or disable it to protect the wider applicable base set.

Server setup

  1. Install and enable STW Persistent Mines GMP on the server, then run the intended scenario and terrain once.
  2. The mod creates $profile:STW/Mines/STWMinesConfig.json.
  3. Stop the server, back up the file you will edit, make valid JSON changes, then restart.
  4. Use the separate AP and AT category-distribution files to tune placement preferences.
Safe editing: do not edit configuration or saved minefield files while the server is running. Start near the defaults and change mine counts or category weights gradually so you can assess their effect on a specific terrain.

Placement-preference files

$profile:STW/Mines/AP/CategoryDistribution.json and $profile:STW/Mines/AT/CategoryDistribution.json independently weight location categories. Higher values make a category more likely; a value of 0 disables it for that mine type.

Persistence

Persistence is enabled by default, with saves every 15 minutes. Surviving mines are restored when the same scenario and terrain are loaded again. Saved minefields are stored in $profile:STW/Persistence/; each scenario and terrain has its own file.

To reset a minefield, stop the server, identify and back up only the matching saved minefield, then move or delete that one file. Start the server to generate a fresh minefield. Do not remove the entire STW persistence folder unless you deliberately intend to reset other STW systems as well.
