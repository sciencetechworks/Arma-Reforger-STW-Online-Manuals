STWSnipers & Spotters

Adds properly equipped sniper/spotter teams to the battlefield: either placed and tailored by a Game Master, or generated automatically in distant overwatch positions where they belong.

STWSnipers & Spotters is an STW mod for Arma Reforger, the military sandbox by Bohemia Interactive. This guide is for players, Game Masters and server administrators.

What arrives on the battlefield

Sniper teams

Each team is a sniper and a spotter with purpose-built weapons, camouflage, ammunition, grenades and optional night vision.

Automatic overwatch

The server can place AI pairs at suitable elevated terrain positions, away from players, and keeps their operating area compact.

Enemy intelligence

Opposing players can receive a deliberately approximate report and map marker—useful warning, not a magic GPS pin.

Game Master control

Turn any editable soldier into a sniper or spotter and select the kit for that individual assignment.

Field support

Automatic teams are resupplied on a schedule and may receive a little medical recovery between engagements.

Server-owned settings

Three small JSON files control equipment, automatic pairs and support without editing the mod itself.

For players: surviving the long view

Most players meet this mod from the receiving end. When automatic pairs are enabled, the server creates one sniper/spotter team for eligible factions at a suitable cached overwatch site. They are kept away from player-controlled characters, stay within a small operating area, and are fitted through the same loadout system used by Game Master assignments.

When intelligence arrives

At intervals chosen by the server, players on the opposing factions receive a message such as an approximate enemy sniper/spotter report. The map also gets a temporary marker. Its position is intentionally offset from the team: treat it as a search area, not a fire mission coordinate. The team’s own faction does not receive that report.

  1. Read the report and open the map; note the approximate area and likely lines of sight.
  2. Approach using folds in the ground, trees, buildings and smoke. Do not stroll across the obvious ridge to investigate a sniper.
  3. Use binoculars, a spotter, suppressive fire or a flank to find the pair. They operate near their overwatch position rather than roaming across the entire map.
  4. Confirm both members are down. The system can replace a missing sniper or spotter later; if the entire pair is destroyed, its replacement appears in a different suitable area after the configured delay.
A good counter-sniper habit: after the first crack, move first and look second. Breaking line of sight, changing elevation and avoiding skyline silhouettes do more for your life expectancy than arguing with the map marker.

For Game Masters: make a pair by hand

In Game Master, select or hover an editable soldier and open the general context actions. Choose STW Assign Sniper or STW Assign Spotter. The assignment dialog lets you choose camouflage, the role’s weapon, muzzle, optic and night-vision option, then press ASSIGN. The unit receives the selected role kit, including ammunition and grenades set by the server.

  1. Place or select two suitable soldiers of the faction you want to use.
  2. Assign one as STW Sniper and one as STW Spotter.
  3. Use matching camouflage for a tidy team, or choose RANDOM for individual variety. Random camouflage excludes Winter from its random pool.
  4. Place them with a believable observation lane and give them orders appropriate to the scenario. The manual assignment equips them; it does not magically invent a mission plan.

To change the clothing and weapon-wrap season on every managed STW sniper and spotter, use STW Set All Snipers/Spotters Camouflage from the general context actions. This is a seasonal refresh, so it updates the camouflage without rebuilding every complete loadout.

Reassigning a unit: an assignment replaces the managed role loadout. Do it deliberately, especially for a soldier carrying scenario-specific equipment.

In-game automatic-generation control

Game Masters can change automatic generation without restarting the running game. Open Scenario Properties, select the STW Snipers tab, and use Automatic Sniper/Spotter Pair Generator. Disabling it immediately removes only system-created pairs; manually assigned snipers and spotters remain. Enabling it starts a fresh automatic-generation pass using the server’s configuration. This is a session-only choice: the next game returns to the JSON configuration’s automaticPairGeneratorEnabled value.

Server setup

Load the mod on the server and start a session once. It creates the configuration folders and default JSON files in the server profile directory:

$profile:STW/Snipers/

On Windows, $profile is the location selected by the server’s -profile startup parameter. Stop the server before editing, keep a backup, then restart it. Each file is validated and rewritten with safe values; invalid values are clamped to their supported range.

FilePurpose
$profile:STW/Snipers/STWSnipersConfig.jsonDefault loadout choices and supply counts for manual and automatic assignments.
$profile:STW/Snipers/AutoPairs/STWSniperPairAutoConfig.jsonAutomatic-pair generation, factions, safe spawn spacing, replacements and intelligence reports.
$profile:STW/Snipers/Support/STWSnipersSupportConfig.jsonScheduled resupply and optional healing for managed teams.
Safe routine: stop server → copy the JSON file → edit with a plain-text editor → check commas and quotes → start server. Let the mod generate the files first; that gives you a valid, current template to edit.

2. Automatic pairs — STWSniperPairAutoConfig.json

The automatic system starts server-side with the game session. It scans terrain progressively, caches viable elevated candidates, creates the initial pairs only once, and uses scheduled callbacks for replacement and intelligence rather than a constant heavy scan. Turning the generator off during a session removes its system-owned pairs; manual assignments are separate.

Balance note: raising pair counts, reducing player exclusion distance, and making reports very accurate all change the mood quickly. Start with the default two initial pairs and test on the real scenario before making the map a sniper convention.

3. Support — STWSnipersSupportConfig.json

Support is server-side and scheduled one due event at a time. At each interval, living automatic-pair members are resupplied; each may also receive a chance-based health recovery. Manually assigned player-controlled units are excluded unless you deliberately opt them in.

SettingDefaultExplanation
version1Configuration format version; leave it mod-managed.
resupplyIntervalDays1Days between due resupply events. Allowed range: 1–24. This is deliberately measured in real session days, not in-game minutes.
healingProbabilityPercent20Chance for each eligible, injured unit to be healed when support is due; 0–100.
healingAmountPercent25Health restored on a successful healing roll; 1–100% of full health.
allowPlayerManagedUnitResupplyfalseWhen true, player-controlled soldiers manually assigned as managed snipers/spotters may receive scheduled resupply and healing too.

A sensible first configuration

For a first live server, leave the automatic system enabled, keep the default two initial pairs, exclude civilians, and leave the 1,200 m player exclusion radius alone. Keep intelligence reports enabled with their default 250 m uncertainty: players get a tense lead without the answer being printed on the map. Use manual Game Master assignments for story missions or defended objectives, and increase pair counts only after watching real performance and player flow.

If the server is cooperative and you want enemy sniper teams to feel like rare roaming hazards, lengthen the report interval and replacement delay. If it is a Game Master-led operation, disable automatic generation and build your teams by hand; it gives you exact control over where the problem is hiding.
