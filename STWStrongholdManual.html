STW Stronghold

A server-side and Game Master stronghold generator for Arma Reforger by Bohemia Interactive. It turns suitable buildings and locations into faction-aligned AI strongholds with garrisons, shooters, patrols, and controllable fist markers.

STW suite connection

STW Stronghold is an STW (ScienceTechWorks) system that runs on the authoritative server. It can be used manually by a Game Master or, when separately enabled, as an automatic map-population system. The core supported faction keys are US, USSR, FIA, RHS_USAF, and RHS_AFRF.

What it adds

A stronghold analyzes a target building or area for viable interior garrison positions, roof or tower shooter positions, and patrol routes. The generated AI is faction-aligned and owned by the stronghold so its lifecycle can be managed cleanly.

Garrison and patrols

Set a unit budget, per-building limit, nearby and surrounding patrol counts, shooter count, and coverage radius. Patrol routes advance in timed legs around the defended location.

Fist-marker workflow

Game Masters create and manage strongholds from STW’s fist-marker draft workflow. Marker visibility can target enemy factions, all factions, or Game Masters only.

Lifetime protection

Strongholds have a time to live. Cleanup can defer while players are nearby, and entry can refresh the lifetime when enabled.

For Game Masters

  1. Use the STW Stronghold placement/draft workflow to place a fist marker at a suitable building or area.
  2. Open the stronghold controls and select a supported faction, then adjust the garrison, patrol, shooter, coverage, marker, and lifetime options.
  3. Generate the stronghold. The system analyzes the location and reports failure if it cannot find eligible positions.
  4. Manage the resulting fist marker with normal STW Stronghold controls; deleting it removes STW-owned AI and the marker while preserving player-controlled entities.

Request limits are validated: 1–10 buildings, up to 12 units per building, up to 8 nearby/surrounding patrols, up to 12 shooters, up to 80 total units, a 50–1000 m coverage radius, and a 0.25–168 hour lifetime. The server-wide maximum total-unit limit can reduce a requested total.

Server setup

  1. Install and enable STW Stronghold, then start the scenario once on the authoritative server.
  2. The mod creates $profile:STW/Stronghold/STWStrongholdConfig.json.
  3. Stop the server before editing configuration, then restart so settings are validated and loaded.
  4. Enable the separate automatic system only when you want scheduled map-populated strongholds.
Capacity planning: strongholds can generate many AI units. Keep server-wide active-stronghold and total-unit caps conservative, particularly when automatic spawning is enabled.

Automatic strongholds

Automatic spawning is off by default and uses $profile:STW/Stronghold/STWAutoStrongholdConfig.json. When enabled, the system scans map tiles for viable building candidates, applies safety and recent-location exclusions, and schedules strongholds for the enabled factions.

  • Default initial spawn delay is randomized from 15 to 45 minutes; replacement delay is 2 to 6 hours.
  • Defaults request one stronghold per enabled faction (US and USSR), with caps for automatic strongholds, combined strongholds, and automatic AI units.
  • It avoids player spawns within 1200 m, uses 1000 m stronghold separation, and prevents recently used locations from recurring for six hours by default.
  • Candidate categories are weighted: military, airfield, command, defence, logistics, industrial, town, and village. Whitelist and blacklist token arrays provide additional location filtering.
  • LIGHT, STANDARD, HEAVY, and CUSTOM difficulty presets control generated-force limits; custom values are explicit per-building, patrol, shooter, and total-unit caps.
