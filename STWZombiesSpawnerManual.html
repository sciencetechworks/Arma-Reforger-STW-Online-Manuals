STW/Zombies

A server-side infected-zone system that places controlled zombie hives in populated areas and unloads distant activity to keep the world responsive.

What it adds

STW/Zombies independently scans populated-looking areas, selects a smaller infected-zone set, and assigns one or more hive candidates according to population. Hives are activated only when players approach them.

Controlled population

The mod-owned wave profile is configured for four zombies per initial hive group: three Shamblers and one Sprinter.

Dynamic activation

Zone state remains lightweight until a player enters the activation radius. Distant hives and their tracked zombies are unloaded.

Persistent clearing

Destroying a hive marks its zone cleared. A genuinely cleared zone is not regenerated during later visits.

For players

There is no player-side setup. Approach an infected-zone marker to activate its hive. The hive may remain visible and destructible while the initial wave is active.

Important: leaving a zone unloads its hive and zombie entities. Returning may reactivate the zone unless the hive was genuinely destroyed.

Server setup

  1. Install and enable STW/Zombies on the server.
  2. Ensure the mod-owned hive override and local wave profile are included.
  3. Start the scenario once so the profile configuration is generated.
  4. Stop the server before editing the configuration file.
  5. Restart and check the script log for population-scan and activation messages.

The profile file is:

$profile:STW/Zombies/STWZombiesConfig.json

Configuration

Values are validated when loaded. Lower the global hive budget if the map has too many infected locations.

SettingDefaultMeaning

markerZoomThreshold1.5Minimum map zoom at which infected markers are shown. Zero disables filtering.
maximumHivesPerZone1Prevents multiple hives in a single selected zone.
Safe tuning: reduce maximumTotalHives first. Keep one hive per zone unless testing demonstrates that a larger population is appropriate.

Hive and zombie lifecycle

The hive uses the mod-owned profile Configs/Spawner/Z_WaveProfile_Small.conf, configured as three Shamblers plus one Sprinter. The overridden hive interval is 7200 seconds. This is deliberately long because the hive remains present after its initial group.

When a player moves away, the hive is unloaded and zombie entities in the zone are cleaned up. When a hive is destroyed through its destruction component, the zone is permanently cleared for that runtime.

Troubleshooting

Too many infected locations

Lower maximumTotalHives, for example from 16 to 4 or 8.

Hives appear but zombies do not unload

Confirm that the server is running the current addon build and inspect the log for Deactivated distant infected zone. Zombie prefab cleanup targets Character_Z_* and does not target ordinary Character_US_* soldiers.

Markers are missing

Confirm that UI/Textures/STW/Zombies/STW_InfectedZoneMarker.edds exists and that showInfectedMarkers is enabled.
