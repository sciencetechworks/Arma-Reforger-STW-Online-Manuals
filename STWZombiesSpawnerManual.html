STW/Zombies

A server-side infected-zone system that places controlled zombie hives in populated areas and unloads distant activity to keep the world responsive.

What it adds

STW/Zombies independently scans populated-looking areas, selects a smaller infected-zone set, and assigns one or more hive candidates according to population. Hives are activated only when players approach them.

Controlled population

The mod-owned wave profile is configured for four zombies per initial hive group: three Shamblers and one Sprinter.

Dynamic activation

Zone state remains lightweight until a player enters the activation radius. Distant hives and their tracked zombies are unloaded.

Persistent clearing

Destroying a hive marks its zone cleared. A genuinely cleared zone is not regenerated during later visits.

For players

There is no player-side setup. Approach an infected-zone marker to activate its hive. The hive may remain visible and destructible while the initial wave is active.

Important: leaving a zone unloads its hive and zombie entities. Returning may reactivate the zone unless the hive was genuinely destroyed.

Server setup

  1. Install and enable STW/Zombies on the server.
  2. Start the intended scenario and map.
  3. Players will see infected areas appear as they approach populated locations.
  4. Use the server’s normal mod-management process when changing the mod or its settings.
Recommended starting point: use the default settings first. They are designed to keep infected activity limited and spread across the map.

Stop the server before changing settings. New values are applied when the server starts again.

Soft dependencies

These mods are optional soft dependencies. STW/Zombies remains usable without them, but they provide the weather-state content and visual atmosphere used by the optional eerie weather feature. Install them on the server and clients when enabling that feature, and verify the configured weather state is available in the scenario.

Neither mod is a hard code dependency. If a soft dependency or its configured weather state is unavailable, the zombie system continues with its own wind and fog controls.

For administrators

The mod automatically chooses a limited number of populated areas. Larger populated areas are more likely to receive infected activity, while distant areas remain unloaded to reduce server activity.

If the server needs fewer infected areas, lower the mod’s overall infected-zone limit. Keep one hive per area for a restrained experience. Changes should be made while the server is stopped and take effect on the next start.

Map markers can be enabled or disabled, and their visibility can be adjusted by map zoom. No player-side configuration is required.
